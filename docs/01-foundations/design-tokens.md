# Design tokens

Tokens are the named values every style and component is built from. Salla uses Material's three tiers.

## Tiers

| Tier | Prefix | Purpose | Who uses it | Example |
|---|---|---|---|---|
| Reference | `ref.` / `--ref-` | Raw palette, scales, fonts. No meaning. | Token build only | `ref.palette.teal.900 = #004956` |
| System | `sys.` / `--sys-` | Roles. Theme-able. The public vocabulary. | Components, product code, Figma variables | `sys.color.primary = {ref.palette.teal.900}` |
| Component | `comp.` / `--comp-` | Values a single component needs that are not plain system tokens. | That component's CSS only | `comp.button.height-md = {ref.size.control.md}` |

Rules:

1. Product and component code reference `sys.*` (and their own `comp.*`). Never `ref.*`.
2. A theme (dark, white-label, partner app) re-maps `sys.*` to different `ref.*`. Components do not change.
3. A `comp.*` token must alias a `sys.*` or `ref.*` token; it never introduces a new raw value.
4. Every raw value in Figma must exist in `ref.*`. If a design needs a value that is not in the scale, the scale is discussed first.

## Files

| File | Format | Consumer |
|---|---|---|
| `tokens/tokens.json` | W3C Design Tokens Community Group (DTCG) JSON with `$type` / `$value` | Style Dictionary / Tokens Studio / Figma variables sync |
| `tokens/css/tokens.css` | CSS custom properties | Any web surface, Storybook, prototypes |
| `tokens/tailwind/preset.js` | Tailwind preset mapped to the CSS variables | Twilight components and the merchant dashboard |

The JSON is the source. The CSS and Tailwind files are hand-maintained today and should be generated by Style Dictionary once the build is in place (`config: css/variables, tailwind/preset`).

## Provenance

Every value in `tokens.json` names the Figma variable it was read from in its `$description`; the raw evidence (variable name → value, per frame) is in `catalog/figma-tokens-harvest.json`, gathered on 2026-09-22 from 20 component frames. Values that were not observed (type sizes above 2xl, radius sm/lg/2xl/4xl/5xl, space 6xl–8xl, shadows sm/xl, motion) are marked `not observed` / `not in Figma` and follow the same scale the observed values sit on.

## Figma mapping

| Figma collection | Token tier | Notes |
|---|---|---|
| `01-*` (primitives, not inspected) | `ref.palette`, `ref.space`, `ref.radius` | assumed to hold the raw scales |
| `02-*` (typography, not inspected) | `ref.font.*` | |
| `03-Colors` (`text / background / border / foreground` × role) | `sys.color.*` | one-to-one, see `docs/02-styles/color.md` |
| `04-Token` (`Spacing/Sizes`, `Radius/Sizes`) | `sys.space.*`, `sys.shape.*` | must absorb the older `spacing/*` and `radius/*` variables |
| Text styles `Bold|Medium|Regular / $text-*` | `sys.typography.*` | see `docs/02-styles/typography.md` |
| (none) | `sys.elevation.*`, `ref.duration.*`, `ref.easing.*` | to be added as effect styles / variables |

## Twilight (code) mapping

The Storybook components read colours as bare HSL channels on `:root` (`--primary: 189 100% 17%`, used as `hsl(var(--primary))` or the Tailwind class `bg-primary`). The full list of 125 root variables is in `catalog/storybook-tokens.json`. Mapping of the roles that matter:

| Twilight variable / class | System token | Note |
|---|---|---|
| `--primary`, `bg-primary` | `sys.color.primary` | code `#004A57`, Figma `#004956` (see color.md drift table) |
| `--primary-200` | `sys.color.primary-disabled` | |
| `--secondary`, `bg-secondary` | `sys.color.primary-container` | code `#A3FFE5`, Figma `#a4ffe5` |
| `--secondary-200` / `-300` | `sys.color.primary-container-subtle` / `-hover` | |
| `--success`, `--danger`, `--warning`, `--info` (+ `-100 … -800`) | `sys.color.status.*` | code ramps have 8 steps; the system keeps the 5 Figma shades and maps `-100` lighter, `-200` light, base primary, `-600` dark, `-800` darker |
